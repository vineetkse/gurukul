# Learning Playground

A student productivity and learning playground built with Next.js, Tailwind
CSS, and TypeScript. The app focuses on visual, interactive study tools such as
timetable planning, science simulations, and math visualizers.

## Key Modules

- Timetable builder with study streaks
- Interactive periodic table and chemistry bond visualizer
- Math graph plotter and geometry tools
- Physics simulations
- Flashcards and formula sheets
- Progress and streak dashboards

## Routes

- `/` Home and roadmap
- `/tools` Timetable builder, flashcards, formula sheets
- `/science-lab` Periodic table, bonds, physics simulations
- `/math-zone` Graph plotter, geometry tools
- `/dashboard` Progress and streaks
- `/community` Future community area

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
